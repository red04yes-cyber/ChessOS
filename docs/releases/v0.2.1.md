# Chess OS 0.2.1

A patch release to validate deterministic dependency installation and the Windows release and updater pipeline.

## Changes

- GitHub Actions now uses `npm ci` on both Linux and Windows so CI installs the exact dependencies recorded in `package-lock.json`.
- Pin the Tauri CLI to 2.12.4 in the package manifest and lockfile.
- Keep the 0.2.0 workspace, analysis, training, and updater improvements.

## Verification

The tagged GitHub Actions workflow must pass frontend tests, the production build, Rust/SQLite tests, Windows installer smoke checks, signed updater bundle generation, and installer checksum verification before publishing this release.
