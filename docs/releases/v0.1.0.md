# Chess OS 0.1.0

Chess OS 0.1.0 is the first MVP rebuild. It is not the recovered historical 0.7.0 application.

## Included

- Interactive chessboard with legal move validation, castling, en passant and all four promotion choices.
- Move timeline, direct move navigation, board rotation, FEN copy and check/last-move highlights.
- PGN import/export, nested RAV variations, branch editing and transposition-aware repertoire graph.
- Local SQLite persistence in the Tauri desktop app, versioned schema migrations and legacy localStorage import.
- Initial move-replay training mode.
- Windows x64 NSIS installer with per-user installation and WebView2 bootstrapper.

## Verification

The Windows CI workflow runs JavaScript tests, the Vite production build, Rust/SQLite tests, and Windows packaging. The current pipeline additionally exercises silent install, app startup, a version-to-version upgrade, SQLite sentinel preservation and uninstall on an ephemeral Windows runner. It uploads the installer and a separate SHA-256 checksum file.

## Known limitations

- FSRS spaced repetition and persistent training history are not included in this baseline.
- Stockfish analysis is not included in this baseline.
- Full SQLite backup/restore, cloud sync, accounts, dashboard analytics and study goals are not included.
- Project license has not yet been selected; no licence grant should be inferred from repository visibility.

## Installation and data

The NSIS package is configured for a current-user installation. Repertoire data is stored in the application data directory in `chess-os.sqlite3`. The application should be closed before replacing or uninstalling it. The installer does not intentionally remove the user's SQLite data on uninstall.

## Release assets

The tag workflow attaches the `chess-os-windows-installer` NSIS executable and the matching `.sha256` checksum file generated by CI. Record the exact commit SHA and verify the checksum after downloading the published asset.
