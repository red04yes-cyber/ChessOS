# Chess OS 0.2.0

A consolidated feature and usability release for the Windows desktop app.

## What is new

- **Cleaner, configurable workspace:** choose light/dark/system theme, accent color, interface density, board size, board colors, coordinates, animation preference, and a compact icon-only sidebar. Studio actions and supporting tools are grouped into smaller menus.
- **Live Studio analysis:** Stockfish evaluates the current position automatically with an evaluation bar. Turn it on or off from the board toolbar.
- **Repertoire practice:** opening exploration and repertoire generation are compact disclosures. Full-line training starts at the beginning and runs through the saved line; random starts stay within the first 12 moves.
- **Game review:** import games, run local Stockfish analysis with estimated accuracy and move quality, review phases and mistakes, and export reports. Tactics, weakness heatmap, and opponent preparation are grouped in the Review workspace.
- **Opponent reports:** download public Chess.com archives by username and create a local profile report.
- **Endgame Lab:** structured lessons, position practice against Stockfish, and Syzygy tablebase checks in a dedicated workspace.
- **More reliable desktop data handling:** improvements to online imports, SQLite backups, board interaction, and application startup.
- **Automatic updates:** the app checks for signed GitHub releases on startup and periodically. A manual check is also available in Appearance settings.

## Update notes

If your installed copy predates the updater, install this release once from the Windows installer attached below. Future signed releases can then install automatically. Repertoire and game data remain in the local ChessOS database.

## Verification

The GitHub release workflow runs JavaScript tests, the production build, Rust/SQLite tests, Windows installer smoke checks, updater bundle signing, and installer checksum verification before publishing assets.
