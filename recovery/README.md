# Recovery fragments — incomplete

These files are **not the Chess OS source tree**. They are the first 16 base64 fragments (parts 00–15) of an attempted transfer of a compressed source archive.

- Expected archive: XZ-compressed TAR payload, split into 30 base64 text fragments.
- Present here: parts 00–15 only.
- Missing: parts 16–29. Some later transfer attempts created incorrect fragment blobs and they are intentionally not included.
- Result: this data cannot be reconstructed into a valid complete source archive and is not buildable.

The files are preserved because the project owner explicitly requested that available incomplete/corrupt material be published. Do not treat this directory as a working source checkout.
